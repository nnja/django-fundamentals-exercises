# Django Fundamentals Exercises

Exercises for [Django Fundamentals](https://fundamentals.learndjango.net/),
a master.dev course taught by Nina Zakharenko. You'll build RescueScout, an
animal rescue site where visitors browse animals and apply to adopt one.

The finished RescueScout site, with a few features not covered by the
course, is in
[nnja/django-fundamentals](https://github.com/nnja/django-fundamentals).

## Getting started

Follow
[Environment Setup](https://fundamentals.learndjango.net/chapters/01-welcome-and-setup/02-environment-setup/)
to install the tools, then
[Setting Up the Project](https://fundamentals.learndjango.net/chapters/01-welcome-and-setup/03-setting-up-the-project/)
to clone this repository, install its development tools with `uv sync`,
and open it in VS Code.
